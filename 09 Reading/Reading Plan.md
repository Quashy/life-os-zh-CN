# 阅读计划

把每天阅读的每章或每节列为一项任务，用 ⏳ 标注计划阅读日期。日记中的「每日阅读」提示框会查询今天及之前的未完成项，因此未读内容会顺延。如果正文保存在笔记库中，可以链接到 `09 Reading/Chapters/` 中的对应笔记。

格式：
```
- [ ] 阅读 [[Genesis 1]] ⏳ 2027-01-01
- [ ] 阅读《Atomic Habits》第 3 章 ⏳ 2027-01-02
```

若使用原版的圣经阅读示例：`scripts/generate_reading_plan.py --start YYYY-MM-DD --days 365` 可生成 1,189 章的阅读计划，`scripts/split_bible.py` 可创建章节和经文笔记。参见 [[07 Workflow - Daily Reading|每日阅读工作流]]。
